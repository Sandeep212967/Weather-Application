# 🌤️ Weather Application

A modern and responsive weather application built using **HTML, CSS, and JavaScript** with real-time weather data powered by WeatherAPI.

## 🌐 Live site 

👉 https://sandeep212967.github.io/Weather-Application/

## ✨ Features

- 🔎 Search weather by city
- 🌡️ Current temperature and weather condition
- 📅 7-day weather forecast
- 🕐 Hourly weather forecast
- 💨 Wind speed and direction
- 💧 Humidity
- 🌧️ Chance of rain
- 👁️ Visibility
- ☀️ UV Index
- 🌡️ Feels-like temperature
- 🔄 Celsius / Fahrenheit toggle
- 📱 Fully responsive design
- 🎨 Modern dashboard UI
- ⚡ Real-time weather data

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- WeatherAPI
- Git & GitHub
- GitHub Pages
